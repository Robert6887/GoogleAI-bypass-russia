## [2.6.0] - 2026-10-20

### Исправлено и улучшено
- **Защита `com.antigravity.bypass.watchdog` от зависаний после сна macOS**:
  - Добавлен сторожевой поток (`_deadman_monitor`), который при зависании цикла более чем на 90 секунд завершает процесс для чистого перезапуска через `launchd`.
  - Пулы потоков переведены на `shutdown(wait=False, cancel_futures=True)`, добавлены таймауты на все вызовы `route`, `dscacheutil`, `killall` и `launchctl`.
- **Отбраковка мёртвых TCP-прокси и защита от самоблокировки**:
  - Недоступные по TCP:443 прокси отсеиваются за один проход (`tcp_tls_dead`) и вычищаются из `known_good_ips.json`.
  - Скачки пинга по Wi-Fi больше не приводят к бану последнего рабочего прокси и откату на непроверенный `fallback_ip`.
  - Штраф на подсеть `/16` применяется только к гео-заблокированным (`RU`) адресам, не затрагивая соседние рабочие серверы при одиночных TCP-таймаутах.
- **Исключена утечка непроверенных IP через `/etc/resolver`**:
  - Для доменов, закреплённых в `/etc/hosts`, в `/etc/resolver/<домен>` оставлен только `nameserver 127.0.0.1`, убран мёртвый DNS `45.155.204.190` и лишние перезапуски `ag_dns`.
- **Расширенный перехват сетевых ошибок**:
  - Добавлена реакция на `operation timed out`, `i/o timeout`, `TLS handshake timeout` и `connection refused` с автоматическим извлечением проблемного IP из `dial tcp <IP>:443`.
- **Отключение QUIC в Chrome**:
  - Добавлено выставление политики `QuicAllowed = false` для стабильной работы веб-версий сервисов через TCP/HTTP2.

## [2.5.0] - 2026-10-16

### ⚡ Улучшено (Changed)
- **Отключён принудительный автозапуск `Gemini.app`**:
  - После завершения настройки утилита больше не открывает навязчиво окно приложения через `open -a /Applications/Gemini.app`.
  - Все необходимые настройки gRPC (`GRPC_DNS_RESOLVER=native`) регистрируются в сессии пользователя, поэтому при самостоятельном запуске приложение работает штатно через изолированный маршрут.
- **Автоматическая публикация релизов (`CI/CD`)**:
  - В workflow GitHub Actions публикация релизов переведена в режим `draft: false` для автоматического создания общедоступных релизов со статусом `Latest`.

## [2.4.0] - 2026-10-15

### 🚀 Добавлено (Added)
- **Автоматический трекинг смены Wi-Fi / сетей (`Network & Gateway Watchdog`)**:
  - Служба `com.antigravity.bypass.watchdog` теперь в реальном времени (каждые 2 секунды) отслеживает изменение физического шлюза (аппаратного роутера `en0`).
  - При переходе между домашним Wi-Fi, офисной корпоративной сетью или мобильным хотспотом статические маршруты `/32` автоматически перестраиваются без перезапуска скрипта и без ввода пароля.
- **Интеграция с реальными логами Antigravity и авто-лечение (`Self-Healing Log Monitor`)**:
  - Монитор логов подключен напрямую к актуальным путям: `~/Library/Logs/Antigravity/language_server.log` и `~/.gemini/antigravity/log/cli-*.log`.
  - При возникновении сетевых ошибок стриминга (`broken pipe`, `connection reset by peer`, `streamGenerateContent ... request failed`) служба мгновенно отправляет сбоящий прокси-узел в карантин и переключает `/etc/hosts` на стабильный резервный сервер из пула.
- **Периодическая калибровка задержек (Canary re-benchmark)**:
  - Снижен порог отсечки деградации узлов с 900мс до 450мс.
  - Каждые 10 минут в фоновом режиме проводится проверка и мягкое переключение на самый быстрый доступный узел.

### ⚡ Улучшено (Changed)
- **Полная автономность (Set-and-Forget)**:
  - Пользователю больше не нужно вручную запускать утилиту при смене локации или сетевых сбоях — Watchdog решает все проблемы в фоне от имени root.
- Обновлен вывод в CLI: отображение текущей версии `v2.4.0` в шапке бенчмарка.
