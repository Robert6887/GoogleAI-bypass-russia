# GoogleAI-bypass-russia

Утилита с единым интерактивным меню `[1–5]` для работы из РФ со всеми сервисами Google AI через собственный **SOCKS5** или **HTTP**-прокси (а также поверх системного туннеля) — параллельно с любыми включёнными VPN/туннельными клиентами и без глобального проксирования всего трафика:

- **Antigravity IDE и CLI** (чат, агент, голосовой ввод и `agy` CLI) + **Автопатч Antigravity** (автоматическое восстановление патча после обновлений IDE)
- **Gemini Desktop** (`/Applications/Gemini.app` на macOS)
- **Gemini в браузере и Google AI Studio** (`gemini.google.com`, `aistudio.google.com`, `notebooklm.google.com`, `generativelanguage.googleapis.com`)
- **Кнопка «Спросить Gemini» в Google Chrome** (встроенная боковая панель GLIC)

## Быстрый старт (macOS — Apple Silicon и Intel)

Ничего собирать вручную и устанавливать Rust не нужно. Откройте **Терминал** и выполните одну команду:

```bash
curl -fsSL https://github.com/Robert6887/GoogleAI-bypass-russia/releases/latest/download/unlock_and_restore.sh | bash
```

Откроется понятное интерактивное меню с живым статусом всех продуктов:

```text
  [1]  Настроить разблокировку продуктов (Antigravity / Gemini / Chrome)
  [2]  Мой прокси и режим VPN (SOCKS5 / HTTP / удалить прокси)
  [3]  Проверить прокси и доступность всех сервисов Google
  [4]  Полный откат (вернуть всё к заводскому состоянию)
  [5]  Сохранить диагностику в файл

  [0]  Выход
```

### Единый поток настройки за минуту

1. Нажмите **`1`** — откроется единый мастер из двух шагов:
   - **Шаг 1 (Выбор продуктов):** отметьте нужные продукты цифрами `1–5` или просто нажмите **`Enter`**, чтобы включить всё сразу (`Antigravity IDE + CLI`, `Автопатч Antigravity`, `Gemini Desktop`, `Gemini в браузере и AI Studio`, `Кнопка «Спросить Gemini» в Chrome`).
   - **Шаг 2 (Прокси):** прямо внутри мастера вставьте купленный **SOCKS5** или **HTTP** прокси (покупать отдельный HTTP-прокси при наличии SOCKS5 не нужно!). Утилита сама определит протокол, проверит доступ к серверам Google, настроит точечный системный `/proxy.pac`, запустит локальный шлюз `127.0.0.1:53129`, включит фоновый автопатч и создаст короткую команду `ag-bypass`.
2. Перезапустите Antigravity и `Gemini.app` (`⌘Q` → открыть снова) и обновите вкладку `gemini.google.com` в Chrome.

> **Важно для кнопки «Спросить Gemini» в правом верхнем углу Chrome (GLIC):** помимо `Local State` (настраивается автоматически при выборе продукта в `[1]`) встроенная панель Chrome требует **личный аккаунт `@gmail.com`** и желательно **прокси с IP США**.

## Поддержка SOCKS5 и HTTP прокси + встроенный чекер (`[3]`)

- Нативно поддерживаются оба протокола: **`SOCKS5`** (RFC 1928 / RFC 1929 с удалённым разрешением доменов `ATYP=0x03` на стороне зарубежного сервера — без утечек локального DNS) и **`HTTP CONNECT`**.
- Можно вставлять строку в любом популярном формате с указанием схемы или без неё (протокол определяется автоматически):
  - `socks5://login:password@ip:port` или `http://login:password@ip:port`
  - `login:password@ip:port`
  - `ip:port:login:password`
  - `ip:port@login:password`
  - `ip:port` (без авторизации)
- В меню **`[2]`** можно в любой момент заменить прокси на лету (без повторного патча и без `sudo`) или **одной кнопкой удалить сохранённый прокси**.
- В меню **`[3]`** встроен отдельный **чекер прокси и гео-блокировки**: можно проверить как текущий маршрут, так и любой только что купленный прокси до сохранения — утилита параллельно опрашивает все 6 сервисов (`Antigravity Daily`, `Antigravity Prod`, `Gemini Web /app`, `Google AI Studio`, `Gemini Desktop`, `Gemini в Chrome`), измеряет пинг в миллисекундах и проверяет, не выдаёт ли Google региональную заглушку («не поддерживается в вашей стране»).

## Работа параллельно с включёнными VPN и туннельными клиентами

По умолчанию включён гибридный физический выход (`bypass`):

- **Прямая привязка к аппаратному адаптеру (`en*` / `IP_BOUND_IF`):** для внешних адресов прокси наш шлюз отправляет пакеты напрямую с физической сетевой карты Wi-Fi/Ethernet, минуя активные виртуальные туннели (`utun` / L3 TUN), даже если одновременно включено несколько туннельных клиентов.
- **Поддержка локальных ядер (`127.0.0.1` / `::1`) и авто-резерв при Kill-Switch:** если в качестве прокси указан локальный порт на этом компьютере либо активный туннель включил жёсткую блокировку трафика вне туннеля на уровне ядра ОС (`includeAllNetworks` / `WFP`), шлюз автоматически без ручных переключений соединяется с вашим прокси через системный маршрут.
- **Прямой системный туннель (`use` / режим `vpn`):** при необходимости в меню `[2]` можно пускать трафик строго через активный системный маршрут (в том числе без отдельного прокси).

Никаких встроенных бесплатных публичных прокси и сторонних SmartDNS-серверов (`DNS-AI`, `Comss`, `Geohide`) в проекте нет — используется исключительно ваш собственный прокси или системный VPN.

## Автопатч после обновлений и глубокий чистый откат (`[4]`)

- **Автопатч Antigravity:** фоновый агент (`com.antigravity.bypass.autopatch` на macOS / задача планировщика на Windows) отслеживает папку установки Antigravity. Как только IDE обновляется, автопатч сначала сохраняет эталонную копию нового бинарника по SHA-256 в `.ag-backups`, дожидается закрытия открытых дескрипторов обновления и автоматически возвращает патч.
- **Полный откат до заводского состояния (`[4]`):**
  - Восстанавливает оригинальные файлы текущей версии Antigravity из локального хранилища `.ag-backups/<sha256>.bin` (скачивать старые установщики `.dmg` не нужно; если Antigravity обновился сам поверх патча, откат не затрёт свежую версию старым файлом).
  - Снимает системный PAC, очищает `AG_LS_PROXY` / `grpc_proxy`, возвращает исходные флаги `Local State` в Google Chrome, удаляет фоновый шлюз, автопатч и сохранённый прокси.
  - Дополнительно вычищает мусор от прошлых и сторонних обходов (`/etc/hosts`, `/etc/resolver/*.ag-backups`, старые системные службы `watchdog` / `ag_dns` и `/Library/Application Support/AntigravityBypass`).
  - **Чаты, история диалогов, воркспейсы, расширения Antigravity и вкладки/пароли Chrome остаются на 100% нетронутыми.**

## Команды CLI (без входа в меню)

```bash
# Открыть интерактивное меню [1–5]
ag-bypass

# Настроить разблокировку и автопатч из консоли
sudo ag-bypass install

# Управление прокси (SOCKS5 / HTTP) и проверка всех 6 сервисов Google
ag-bypass proxy set
ag-bypass proxy test
ag-bypass proxy status
ag-bypass proxy clear

# Управление автопатчем Antigravity
ag-bypass autopatch enable
ag-bypass autopatch status
ag-bypass autopatch disable

# Переключить режим или политику VPN
ag-bypass mode own-proxy
ag-bypass vpn bypass

# Разблокировать кнопку «Спросить Gemini» в Chrome
ag-bypass chrome-gemini

# Проверка доступности и полный чистый откат
ag-bypass doctor
sudo ag-bypass rollback
```
