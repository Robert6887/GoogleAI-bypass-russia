## What's Changed in v2.5.0

### ⚡ Улучшения и исправления
- **Отключён принудительный автозапуск Gemini.app**:
  - Утилита больше не открывает окно `Gemini.app` автоматически после выполнения настройки и сброса сетевых параметров.
  - Настройки gRPC (`GRPC_DNS_RESOLVER=native`) регистрируются в пользовательской сессии `launchctl`, поэтому при самостоятельном запуске приложение работает штатно через выделенный IPv4-маршрут без утечек IPv6.
- **Автоматическая публикация релизов в GitHub Actions**:
  - Пайплайн сборки настроен на автоматическую публикацию релизов (`draft: false`), чтобы новые версии сразу становились публичными и получали статус `Latest`.

**Full Changelog**: https://github.com/Robert6887/GoogleAI-bypass-russia/compare/v2.4.0...v2.5.0
